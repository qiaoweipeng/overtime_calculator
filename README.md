### 自动化加班数据核查工具

这是一个基于 Python 的自动化脚本，用于快速核对 Excel 考勤数据并计算加班时长。

#### 核心功能

- 根据核对规则，自动核对所有员工的加班时长是否正确。
- 自动导出核对报告（md格式）。
- 自动导出Excel格式的核对数据表格。

#### 核对规则

| 规则项目             | 说明                                |
| -------------------- | ----------------------------------- |
| 加班起算时间         | 19:00之后才算加班                   |
| 不足30分钟           | 不计入加班                          |
| 超过30分钟不足1小时  | 计算为30分钟                        |
| 超过1小时不足1.5小时 | 计算为1小时                         |
| 计算单位             | 以30分钟为单位向下取整              |
| 跨午夜情况           | 凌晨时间（如00:07）视为当天加班延续 |

#### 快速开始

1. **环境依赖**

​	在运行脚本前，请确保你的环境中安装了 Python 3.7+，并安装了依赖库。

2. **准备数据** 确保你的 Excel 文件（如 `data.xlsx`）包含名为 `深圳` 的工作表（Sheet），且第一行为包含日期的表头。

- 表头格式示例：`工号` | `姓名` | `05-01 星期五` | `05-02 星期六` | ...

3. **运行脚本** 在命令行中执行以下命令：

```bash
python overtime_calculator.py

或

python3 overtime_calculator.py // python V3以上版本
```

4. **获取结果** 脚本运行完成后，会在当前目录下的 `output` 文件夹中生成核算结果文件。

#### 参数说明与自定义

如果你需要处理不同城市或特定月份的数据，可以在代码中调整 `calculate_overtime` 函数的参数：

| 参数名             | 默认值                             | 说明                                                         |
| ------------------ | ---------------------------------- | ------------------------------------------------------------ |
| `input_excel_path` | `data01.xlsx`                      | 待处理的原始 Excel 文件路径                                  |
| `sheet_names`      | `['深圳', '武汉', '长沙', '梅州']` | 需要核算的工作表名称列表，默认处理这四个城市，如果只想核对单个城市，只需删除列表中其他城市名称即可 |
| `output_dir`       | `./output`                         | 结果文件的输出目录                                           |

#### 常见问题排查

- 报错：未找到日期列
  - 请检查 Excel 的 Sheet 名称是否与代码中的 `sheet_names` 一致。
  - 请检查表头日期格式是否符合 `MM-DD 星期X` 的规律。
- 报错：自动识别月份失败
  - 脚本会自动抓取表头中第一个符合 `XX-XX` 格式的月份。如果表头极其不规范，建议手动在代码中指定 `target_month`。
