# 自动化加班数据核查工具

这是一个基于 Web 的自动化工具，用于快速核对 Excel 考勤数据并计算加班时长。

## 核心功能

- 根据核对规则，自动核对所有员工的加班时长是否正确
- 支持多城市工作表选择（深圳、梅州、长沙、武汉、广西）
- 直接在浏览器中查看核对报告，无需生成文件

## 核对规则

| 规则项目         | 说明                   | 示例                      |
| ------------ | -------------------- | ----------------------- |
| 加班起算时间       | 19:00之后才算加班          | 18:59下班 → 0分钟           |
| 不足30分钟       | 不计入加班                | 19:25下班 → 0分钟（加了25分钟）   |
| 超过30分钟不足1小时  | 计算为30分钟              | 19:55下班 → 30分钟（加了55分钟）  |
| 超过1小时不足1.5小时 | 计算为1小时               | 20:55下班 → 60分钟（加了115分钟） |
| 计算单位         | 以30分钟为单位向下取整         | —                       |
| 跨午夜情况        | 凌晨时间（如00:07）视为当天加班延续 | 00:07下班 → 300分钟（5小时）    |

## 快速开始

### 环境要求

- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 无需安装任何依赖

### 运行方式

直接双击打开 `index.html` 文件即可使用。

### 使用步骤

1. **打开页面**：双击 `index.html`，在浏览器中打开
2. **上传文件**：点击或拖拽 Excel 文件到上传区域
3. **选择工作表**：勾选需要核对的城市（默认勾选深圳）
4. **开始核对**：点击绿色"开始核对"按钮
5. **查看报告**：报告直接显示在页面下方

### 支持的工作表

仅支持以下城市名称的工作表（精确匹配）：

- 深圳
- 梅州
- 长沙
- 武汉
- 广西

如果 Excel 文件中缺少某个城市的工作表，则不会显示对应的选项。

### 准备数据

确保你的 Excel 文件包含以下格式的表头：

| 工号     | 姓名     | 部门     | 05-01 星期五 | 05-02 星期六 | ...    | 加班总时长/小时 |
| ------ | ------ | ------ | --------- | --------- | ------ | -------- |
| <br /> | <br /> | <br /> | <br />    | <br />    | <br /> | <br />   |

**日期列格式**：支持多种格式

- `MM-DD`（如 `05-01`）
- `MM-DD 星期X`（如 `05-01 星期五`）
- `MM/DD`（如 `05/01`）
- `6月1日`（中文格式）

## 报告内容

生成的核对报告包含以下内容：

- **核对结论**：显示核对结果和差异数量
- **加班明细**：各人员加班时长汇总表
- **加班时长TOP 10**：加班时长最多的前10名人员
- **核对规则**：核对规则说明（在页面底部）

### 报告特点

- **左侧锚点导航**：点击即可快速跳转到相应区域
- **多城市切换**：如果选择了多个城市，可通过标签切换查看
- **差异行高亮**：有差异的行显示红色背景
- **状态图标**：✅ 表示一致，❌ 表示有差异
- **响应式布局**：支持桌面端和移动端浏览

## 常见问题排查

### 报错：未找到日期列

- 请检查表头第一行是否包含日期列
- 日期格式是否符合支持的格式

### 报错：工作表不存在

- 请确认 Excel 文件中包含支持的城市工作表
- 支持的工作表名称：深圳、梅州、长沙、武汉、广西

### 警告：未找到'加班总时长/小时'列

- 脚本会继续执行，但无法进行差异核对
- 请确认表格中包含名为 `加班总时长/小时` 的列

## 注意事项

1. 工具以只读模式读取 Excel 文件，不会修改原文件
2. 输入文件必须是 `.xlsx` 格式，不支持 `.xls` 格式
3. 日期列必须在表头中
4. 加班计算规则为：19:00后开始计算，不足30分钟不计，超过30分钟按30分钟为单位向下取整
